Step 1 — RSA Key Generation

Key Generation
ℹ️

Generates a key pair using two prime numbers p = 61 and q = 53.

Computes: n = p × q = 3233  |  φ(n) = (p−1)(q−1) = 3120  |  e = 17  |  d = e⁻¹ mod φ(n) via Extended Euclidean Algorithm

1 Select primes: p = 61, q = 53
2 Compute modulus: n = p × q = 3233
3 Euler's totient: φ(n) = (p−1)(q−1) = 3120
4 Choose public exponent: e = 17 where gcd(e, φ) = 1
5 Compute private key: d = e⁻¹ mod φ(n) (Extended Euclidean)

Step 2 — Sign a Document

Signing
ℹ️

Hash the document using a custom polynomial rolling hash, then encrypt the hash with the private key.

σ = H(message)d mod n  —  Square-and-Multiply modular exponentiation

Step 3 — Verify Document Authenticity

Verification
ℹ️

Recover the hash from signature using the public key, then compare with recomputed hash.

If σe mod n == H(message) → VALID  |  else → TAMPERED

Why Verification Failed — The Science

1

The signature was computed as σ = H(original)d mod n using the original document's hash.

2

Verification recovers: σe mod n → this gives back H(original).

3

But we now compute H(tampered) — a completely different value due to the changed content.

4

H(original) ≠ H(tampered) → Verification FAILS. This is RSA digital signature integrity in action.
